# CCNA Lab

[Ouvrir le QCM](https://aloyslrtg.github.io/ccna-lab/)

- **Modules 8–10** : 62 exercices, texte fourni conservé.
- **Modules 11–13** : 57 exercices, basés sur les données et réponses de la [page de référence](https://ccnareponses.com/modules-11-13-examen-sur-ladressage-ip-reponses/), avec énoncés et explications reformulés.

Choisis ta série sur le tableau de bord. Chaque banque possède ses questions, ses sessions en pause, ses erreurs et son historique. Les activités Packet Tracer sont retirées (n° 5 pour 8–10 et n° 29 pour 11–13).

Entraînement avec correction immédiate ou examen avec bilan final ; séries de 10, 20, 56 questions ou banque entière ; questions et propositions mélangées sans répétition. Les associations sont interactives et les schémas sont intégrés sans afficher les réponses.

Le fichier `index.html` est autonome et fonctionne aussi hors ligne dans un navigateur. Les résultats sont enregistrés uniquement dans le navigateur utilisé.
